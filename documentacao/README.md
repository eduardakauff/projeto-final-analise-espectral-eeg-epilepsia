# Documentação

Esta pasta reúne documentos, referências científicas e informações técnicas relacionadas ao desenvolvimento do projeto de análise espectral de sinais EEG para classificação de períodos ictais e interictais associados à epilepsia.
Serão armazenados:

Referências dos artigos científicos utilizados;

Informações e metadados da base de dados escolhida;

Documentação dos métodos de processamento e classificação.
