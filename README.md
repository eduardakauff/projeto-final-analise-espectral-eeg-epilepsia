# Projeto final

Problema escolhido:

Identificação de alterações no conteúdo espectral dos sinais EEG para diferenciar períodos ictais (durante crises epilépticas) e interictais (entre crises).
Item no artigo: Domínio da frequência

Tema do projeto:

Análise espectral de sinais eletroencefalográficos para classificação de períodos ictais e interictais associados às crises epilépticas utilizando algoritmos de aprendizado de máquina.

Objetivo:

Aplicar a Transformada Rápida de Fourier (FFT) e os algoritmos de aprendizado de máquina SVM e Random Forest aos sinais EEG da base pública (a definir) para identificar e classificar períodos ictais e interictais, avaliando o desempenho por meio das métricas (a definir) em relação aos rótulos de referência definidos a partir das anotações dos horários das crises epilépticas.
